# Alpha 发布检查

以下是发行门槛，不是已完成声明。源码发布与普通用户安装包分别验收。

1. 复核 `release-files.txt` 与最终树；不包含历史仓、个人资料、诊断、账户配置、缓存、歌词库或未许可媒体。
2. 使用本地成熟秘密扫描器扫描最终树与全部拟公开 refs；用仓库外的私有词表复核身份与本机路径。扫描报告不提交。当前树通过不能替代历史／元数据检查。
3. 保留 LICENSE、NOTICE 与解析器 MIT；核对每个外部服务的许可、地区及速率条款。公开维护身份、正式 Bundle ID、反馈与私密安全渠道需确认。
4. 在不带私人配置的环境运行严格离线测试和应用构建；另做首次启动、系统权限允许／拒绝、菜单／浮层、设置恢复、卸载与升级验证。离线通过不等于真实播放器或人工听感通过。
5. 按文件白名单导出源码归档，解包复核内容并再扫秘密。核对二进制 strings、签名身份、权限与附带许可证，将验证记录绑定最终文件 SHA-256。不要打包整个工作目录。
6. 普通用户安装包需单独完成 Developer ID、hardened runtime、签名、公证及 Gatekeeper 验收；[Apple 发行说明](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)。ad-hoc 产物不是公证发行包，不要求用户关闭系统安全保护。
7. 确认精确托管账号、仓库、公开范围和版本；仅在明确批准后创建远端、推送或上传。不要将私人父链、检查点 refs 或签名证书带入新公开仓。

开发者工具：`python3 scripts/public-source.py check` 检查清单完整性；`archive` 仅按清单打包，不包含 `.git`、构建输出或配置。脚本不能替代内容审查。依赖或源码发生变化后重新扫描与构建，不能沿用旧版本放行结论。
