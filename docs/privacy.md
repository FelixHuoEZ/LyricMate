# 隐私与数据

本 Alpha 不包含上游遥测模块或遥测密钥，不提供账户登录或诊断上传功能。

## 读取与联网

开启跟随后，通过 macOS Apple Events 读取已运行 Spotify 的歌名、歌手、专辑、时长、歌曲标识、播放状态与进度。需由用户授予系统自动化权限。仅点击控制按钮时才发送播放控制；不读取登录 Cookie 或音乐音频。

搜索会将歌名、可选歌手及必要歌曲标识发送给内置 LRCLIB 和主动启用的其他来源。仅歌名回退会再次查询。服务方仍能获知 IP、请求时刻和查询内容；HTTPS 不会向服务方隐藏这些信息。添加自定义源意味着信任其接收查询。当前没有独立的全局离线开关；完全不希望联网时不要连接跟随或发起搜索。

## 本机保存

- 配置保存在 UserDefaults 域 `local.lyricmate.alpha.daily.v1`，包括连接恢复、浮层外观与位置、来源配置、候选选择和时间偏移。
- 本地歌词保存在应用支持目录下 `local.lyricmate.alpha/local-lyrics`。只导入有权使用的文件，不随源码或发行包附赠。
- 故障现场保存在 `local.lyricmate.alpha/diagnostics/incidents`，最多 20 份、7 天、总计 10 MB；包括步骤、耗时、错误类别和进程诊断，不含歌词正文或凭据。写盘失败不阻断播放跟随。
- 手动“保存同步诊断”写入 `local.lyricmate.alpha/diagnostics/manual`。它含歌曲标识、歌名、歌手、专辑、播放位置、时间戳、候选元数据、进程与错误信息，不含歌词正文。分享前必须审查；手动文件不参与自动现场的 7 天清理。
- 设置备份可能包含来源地址、已确认录音身份与偏移，是私人数据，不是公开示例。

本候选与其他版本隔离，不自动导入其他版本的设置。移除应用不会自动删除配置／本地歌词。卸载清理前应自行备份需要保留的文件，仅删除本 Alpha 的配置域与对应支持目录，避免影响其他应用。系统自动化权限可在 macOS 隐私设置中管理。

不承诺系统崩溃报告、外部服务日志或用户主动分享的资料可由本项目删除。对外反馈只需最小化、脱敏的复现步骤。
