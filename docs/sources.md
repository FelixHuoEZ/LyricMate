# 歌词来源与发行边界

当前无附赠歌词文件、音频、账户密钥、Cookie 或源脚本。技术接口可访问不等于服务授权或歌词再分发许可。

| 来源 | 当前实现 | 候选默认 | 权利与可用性边界 |
| --- | --- | --- | --- |
| LRCLIB | 歌名／歌手搜索与逐行歌词 | 内置 | [服务文档](https://lrclib.net/docs)；带应用名、版本、项目链接；跨客户端串行、响应后至少 250 ms 间隔及共享 429 冷却。不保证内容权利 |
| AMLL TTML DB | 受限公开索引与 TTML 解析，呈现逐行 | 不添加 | [仓库](https://github.com/amll-dev/amll-ttml-db)标示 CC0；不因此推定原歌词权利已获授权，也不捆绑曲库 |
| 酷狗、网易云、酷我、QQ 音乐、咪咕 | 实验代码及原历史保留，运行注册器拒绝构造 | 不可启用／测试 | 非官方开放 API；未完成接入／展示权利确认，不作为源码 Alpha 提供的在线功能 |
| 自定义 HTTPS JSON | 文件／粘贴清单 | 空 | 仅格式兼容，不代表信任或授权；启用者需确认接收查询的服务 |
| Musixmatch、LyricFind | 未接入，仅官方入口 | 无请求 | 需正式 API、时间轴权限及展示条款；不使用第三方令牌或绕过接口 |

源管理不再提供五个平台的一键添加；导入同类格式会拒绝，旧配置原样保留但界面不可启用／测试，运行注册器也拒绝构造。未修改既有保存键、来源 ID 或 enabled 标志，恢复备份也不能绕过运行策略。自定义 JSON 仅为受限协议，仍需启用者确认服务与权利，不是获准代理这些平台的承诺。

保留实验代码和四条原提交是既定历史边界，不意味着已完全移除法律风险。公开自有适配器代码、执行请求、经营服务及再分发歌词是不同事项；本轮只收窄在线功能，不声称已取得平台或逐首内容授权。若要求历史中也不能出现实现，需要另行决定历史方案，不在本轮改写。

平台错误、超时与无候选分别显示。歌词评分是元数据启发式排序，不是正确率；无时间轴歌词不用于实时同步。来自不同专辑、现场或翻唱的歌词需要录音核对，不因能显示而视为验收通过。
